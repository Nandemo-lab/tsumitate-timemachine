## 分類基準

- A: 実在する投資信託の基準価額実績
- B: ETFの市場価格
- C: ETFのNAV
- D: 指数Price Return
- E: 指数Total Return
- F: 独自推計
- G: 出典不明

## 一次情報との照合で確認した不一致例

- INDA公式のCalendar Year Total Returnは2021年22.41%、2022年-9.38%、2023年17.49%、2024年8.99%。現行コード値とは一致しない。
- EEM公式のCalendar Year Total Returnは2021年-3.72%、2022年-20.55%、2023年8.90%、2024年6.94%。現行コード値とは一部一致せず、丸め差だけでは説明できない年がある。
- このため、現行値をETF Total Returnとして再分類せずGを維持する。系列全体の基準を統一して再構築できるまで、部分的な数値置換は行わない。
