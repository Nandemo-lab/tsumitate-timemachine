## 2. GA4イベント定義と集計

Google tagとカスタムイベントは `tsumitate-timemachine.com` だけで送信する。ローカル、Vercel preview、IP直打ちでは送信しない。手動 `page_view` は送らず、Google tagの履歴変更計測だけを使用する。

| イベント | 発火点 | 重複防止・注意 |
|---|---|---|
| `simulation_start` | 単一・ランキング画面で最初に条件変更または実行 | React mountごとにrefで1回 |
| `simulation_complete` | 同期計算が例外なく完了した実行 | 再実行は別の利用行動として送信 |
| `compare_start` | 比較フォームで最初に条件変更または実行 | React mountごとにrefで1回、completeより先 |
| `compare_complete` | 両商品の同期計算が例外なく完了した実行 | 再実行は別の利用行動として送信 |
| `share` | URLコピーまたは共有処理が成功 | クリックだけの旧`share_click`と区別 |
| `source_view` | 利用者がデータ出典リンクを開く | surfaceのみ送信 |
| `return_visit` | 保存条件がある端末でJST日付が前回表示日より後 | 同日再マウントは送信しない。端末・ブラウザをまたぐ再訪ではない |

商品ID、開始年、月額、画面識別子以外の自由入力は送らない。氏名、メール、共有URL、評価額、元本、損益、利益率は送らない。

11月評価はGA4探索で**セッション単位**に次を集計する。

1. Organic Landing → Simulation Start
   - 分母: 対象期間のOrganic Searchランディングセッション
   - 分子: 同じセッションに`simulation_start`
2. Simulation Start → Complete
   - 分母: `simulation_start`を含むセッション
   - 分子: 同じセッションに`simulation_complete`
3. Compare Start → Complete
   - 分母: `compare_start`を含むセッション
   - 分子: 同じセッションに`compare_complete`
4. Complete → Share
   - 分母: `simulation_complete`または`compare_complete`を含むセッション
   - 分子: 同じセッションに`share`
5. 保存条件を使う再訪
   - 分母: 対象期間の全セッション（別案では全active users。採用した母数を固定して明記）
   - 分子: `return_visit`を含むセッション（またはusers）

2026-10-12のローカルQA混入（`page_view` 158、予測11）は修正前データであり、自然利用者の値として比較しない。2026-10-13以降も本番ドメインで行う手動QAは自然流入と区別できないため、QA日時・操作を記録し、イベント数の小さい初期期間では参考値として扱う。
